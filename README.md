# 8mrot

Бесплатный мини-сайт «Анна про пособия» для предварительной проверки правила 8 МРОТ при назначении единого пособия.

## 2026
- МРОТ: 27 093 ₽
- 8 МРОТ: 216 744 ₽
- При уважительных причинах порог уменьшается пропорционально.
- При 10 и более месяцах уважительных причин минимальный порог не применяется.
- Официальная безработица: учитывается максимум 6 месяцев.
- С 21 июля 2026 года уход за нетрудоспособным учитывается как уважительная причина при уходе за близким родственником, при соблюдении требований правил.

Нормативная основа: Постановление Правительства РФ от 16.12.2022 № 2330 (с действующими изменениями) и разъяснения СФР.

Страница: `index.html`.
